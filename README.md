# Inteligencia Artificial en el Borde para Boya Oceanográfica de Alerta Temprana de Tsunamis

Repositorio oficial con los códigos fuente correspondientes al Proyecto de Título. 

## Estructura del Proyecto
* **/Generacion_Datos:** Scripts en Python para descargar batimetría (GEBCO), procesar olas sintéticas e inyectar anomalías sísmicas (Maule 2010, Illapel 2015).
* **/Modelos_IA:** Arquitectura LSTM y detección de anomalías (Isolation Forest, Random Forest) desarrollados en TensorFlow/Keras.
* **/Simulaciones_MATLAB:** Evaluaciones del comportamiento hidrodinámico y propagación.
